# Code Review

Read the target repository's `AGENTS.md` and its project constraints. Apply
`ai/roles/code-reviewer.md` to the requested diff or the working tree by default.

Stay read-only. Report actionable findings first with severity, file/line evidence, consequence,
and a concrete correction. End with a verdict and material verification limits.
