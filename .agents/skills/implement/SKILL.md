# Implement

Read the target repository's `AGENTS.md` and its project-context documents. Follow
`ai/workflows/implement.md` for implementation and handoff.

Use the project's commands, architecture, data constraints, UI guidance, and definition of done.
Preserve existing user work. When a ticket is supplied, assign it to the user. After required
verification and reviews pass, commit on a feature branch, push it, and create a pull request.
Follow any explicit user limit on delivery scope; merging and deployment require separate scope.
Report the PR URL, validation, and remaining limits.
