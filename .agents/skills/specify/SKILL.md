# Specify

Read the target repository's `AGENTS.md` and the project-context documents it names. Follow
`ai/workflows/specify.md` using `ai/roles/requirements-analyst.md`.

Deliver a reviewable spec in the requested location. Resolve material questions and check that
each criterion fits this task's scope and dependencies. Create an external issue only when that
delivery is authorized. Finish at the spec; implementation is a separate task.
